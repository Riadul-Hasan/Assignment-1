
# TypeScript Assignment 1

## Overview

This repository contains my TypeScript Assignment 1, including coding solutions and two technical blog posts. The main goal of this assignment is to practice TypeScript concepts through practical examples and improve my understanding of type-safe programming.

## Coding Solutions

The `solutions.ts` file contains practical TypeScript problems and their solutions. These exercises cover different programming concepts, including:

- Optional function parameters and default behavior.
- Union types and type narrowing.
- Readonly tuples and coordinate formatting.
- Generic functions for reusable array operations.
- Interfaces and filtering course information.
- Generic constraints using `keyof` and `T[K]`.
- Classes, inheritance, and access modifiers in OOP.

## Technical Blog Posts

This assignment also includes two separate technical blog posts:

**1. Type vs Interface in TypeScript**

Explains the key differences between type aliases and interfaces, their features, and when to use each.

**2. Generics in TypeScript and Promise<T></t>**

Explains how generics work, how they improve code reusability, and how they help maintain type safety when handling asynchronous operations.

## How to Run

First, make sure TypeScript is installed:

```bash
npm install -g typescript
```

Compile the TypeScript code:

```bash
tsc
```

The compiled JavaScript files will be generated according to the configuration in `tsconfig.json`.
